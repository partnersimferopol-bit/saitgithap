# Сайт Екатерины Зверевой

Один файл `index.html`. Его можно открыть двойным щелчком или выложить на GitHub Pages.

## Как опубликовать на GitHub

1. Создайте новый репозиторий на GitHub (можно пустой, без README).
2. Загрузите в него содержимое этой папки: `index.html` и `.nojekyll`.
3. Откройте Settings → Pages.
4. В разделе Build and deployment выберите Branch: `main` и папку `/ (root)`.
5. Сохраните. Через минуту сайт откроется по адресу `https://ВАШ-ЛОГИН.github.io/ИМЯ-РЕПОЗИТОРИЯ/`.

Страницы внутри файла переключаются сами. Форма заявки только показывает подтверждение на экране и никуда не отправляет данные.
